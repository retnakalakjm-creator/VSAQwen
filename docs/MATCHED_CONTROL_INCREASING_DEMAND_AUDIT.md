# Matched-Control Increasing Demand Audit

This audit tests whether `increasing_demand` is associated with different outcomes beyond comparable unchanged scanner decisions.

Controls are matched within the same symbol, direction, trend state, horizon, and presence of `increasing_demand`, with bounded differences in professional score, net pressure, and VSA evidence age.

The audit is diagnostic only. It does not change scanner scoring, qualification, or production behavior.

A positive target-minus-control return delta suggests the changed cases performed better than comparable unchanged cases; a negative delta suggests worse performance. Small matched samples must not be treated as evidence for production rule changes.
